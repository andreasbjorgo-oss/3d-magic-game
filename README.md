# 3D Magic Gloves Game 🎮✨

Et morsomt 3D-spill der du bruker magihansker til å kaste stavene mot fiender!

## Hvordan Spiller Du?

### 🎮 Mobil Kontroller:
- **Dra fingeren** på skjermen for å bevege deg rundt
- **Trykk raskt** (tap) et sted på skjermen for å skyte magi i den retningen
- Magihansker endrer farge basert på valgt stavtyp

### ⌨️ Tastatur Kontroller (Desktop):
- **Piltaster**: Beveg deg rundt
- **1**: Velg Ildmagi (rødt)
- **2**: Velg Frostmagi (blått)
- **3**: Velg Lynnmagi (gult)
- **Space**: Skyt magi fremover

## 🔥 Stavtyper

### Ildmagi (FIRE)
- 🎯 Raskest stavtyp
- 💥 God skade
- ⏱️ Kjølningstid: 0.5 sekunder
- Farge: **Rødt**

### Frostmagi (FROST)
- 🧊 Fryser fiender på stedet
- 💥 Medium skade
- ⏱️ Kjølningstid: 0.7 sekunder
- Farge: **Blått**

### Lynnmagi (LIGHTNING)
- ⚡ Kraftigste stavtypen
- 💥 Høyest skade
- ⏱️ Kjølningstid: 0.9 sekunder
- Farge: **Gult**

## 📊 Spillmekanikk

- **Helse**: Du starter med 100 HP
- **Fiender**: De jager deg og gjør 5 skade per berøring
- **Poeng**: 10 poeng per drepet fiende
- **Vanskelighet**: Flere fiender jo lenger du overlever

## 💡 Tips

1. **Bruk Frostmagi** for å fryse fiender som kommer for nær
2. **Bytt stavtype** strategisk basert på situasjonen
3. **Beveg deg** i sirkler for å unngå å bli omgitt
4. **Fokuser på** fiendene som er nærmest deg først

## 🚀 Ødelegg alle fiendene og få høyest mulig poengsum!
